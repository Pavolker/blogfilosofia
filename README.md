# Sinapses do Vento

Landing page estática do livro *Sinapses do Vento*, de Angélica Sátiro e Paulo Volker.

O site não possui backend, cadastro, administração ou banco de dados. Todas as interações são navegação interna ou links externos, incluindo a página de compra na Hotmart.

## Estrutura

- `index.html`: conteúdo e estrutura da página
- `style.css`: estilos responsivos
- `script.js`: idioma português/espanhol e animações de entrada
- `sidebar.js`: menu lateral e páginas informativas
- imagens locais: capa, autores e páginas do livro

## Publicação

O arquivo `netlify.toml` publica a raiz do projeto diretamente. Não há dependências, variáveis de ambiente nem etapa de build.

Para visualizar localmente, abra `index.html` em um navegador ou sirva a pasta com qualquer servidor HTTP estático.
